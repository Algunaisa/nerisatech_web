# 🚀 Nerisa Tech

Navegando ideas, creando tecnología.

Bienvenido al repositorio oficial de Nerisa Tech.

Somos una empresa enfocada en el desarrollo de aplicaciones móviles, videojuegos y experiencias digitales. Nuestro objetivo es transformar ideas en productos tecnológicos útiles, accesibles y atractivos para personas y empresas.

---

## 🌊 Nuestra historia

Nerisa Tech nace de la unión de dos nombres:

- Isa

Inspirados por la idea de explorar nuevos horizontes, buscamos navegar junto a nuestros clientes desde una idea inicial hasta un producto terminado.

Diseñar y desarrollar aplicaciones móviles y experiencias digitales que permitan a personas y empresas convertir sus ideas en productos tecnológicos accesibles, útiles y atractivos.

🤝 Cómo contribuir

Si formas parte del equipo:

1. Crea una rama nueva.
2. Realiza tus cambios.
3. Haz commit describiendo lo que modificaste.
4. Sube los cambios.
5. Solicita revisión antes de fusionar.

Ejemplo:

git checkout -b nueva-funcionalidad
git add .
git commit -m "Agrega sección de contacto"
git push origin nueva-funcionalidad
